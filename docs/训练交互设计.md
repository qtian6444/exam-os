# Learning OS 训练交互设计（MVP · 规则化 AI）

> 说明：所有「AI 反馈」= 规则库比对 + 固定模板 + 数据映射，无生成式 LLM。能力维度固定 5 维：**词汇 / 长难句（代码里叫 sentence）/ 阅读 / 听力 / 写作**。

---

# Part 1 · 训练空间整体结构

## 1.1 页面骨架（竖屏，宽度 ~480px，移动端优先）

```
┌──────────────────────────────┐
│ ← 返回   长难句·句子排序   2/6 │  顶部：进度 + 模块名
│  ▓▓▓▓▓▓░░░░░░░░░░░░░░░░░░░░  │  进度条（已完成/总题数）
├──────────────────────────────┤
│                              │
│        题 面 区（可滚动）      │  中间：题干/文章/音频/图片
│                              │
│                              │
├──────────────────────────────┤
│   [操作区]                    │  底部：选项 / 输入框 / 碎片拖拽
│   [  提交  ]                  │       主按钮「提交」
└──────────────────────────────┘
        ↓ 提交后，从底部弹出
┌──────────────────────────────┐
│  反馈层（弹层，非右侧常驻）     │
│  ① 为什么错 ② 错在哪 ③ 下一步   │
│  [ 再试一次 ]  [ 下一题 ]      │
└──────────────────────────────┘
```

> 关键决策：**反馈做成「答后弹出的底部层」而不是「右侧常驻栏」**——手机宽度放不下右侧栏；听劫的「AI 辅助区」在移动端应折叠成弹层，答完才展开，避免打扰思考。

## 1.2 统一判题规则（确定性）

- **选择题**：用户选项 ID == 正确答案 ID。
- **排序题**：用户序列 == 正确序列（逐位一致）。
- **文本题**：归一化（去空格/大小写/标点）后 == 参考答案集合中任一个。
- **匹配题**：每一对都命中才算对。

## 1.3 统一反馈机制（三要素，不直接甩答案）

| 要素 | 规则来源 | 展示 |
|---|---|---|
| **为什么错** | 题型规则（如「这是主从复合句，先找主句」） | 一行原因 |
| **错在哪** | 高亮/标红用户答错的**具体位置**（错误选项、错放碎片、拼错字母） | 视觉定位 |
| **下一步练什么** | 映射到 5 维能力 → 指向该题型对应的薄弱维度 | 一行建议 |

## 1.4 统一强化闭环（Duolingo 式，一次错误不结束）

```
第一次错误
   ↓ （不给答案）
提示：定位错误点 + 一句规则提示
   ↓
再次尝试：同题重答（或简化版）
   ↓ 仍错
解析：完整展示正确 + 原因，标记对应能力维度
   ↓ 收尾
类似题强化 1 题 → 答对才算完成本题
```

# Part 2 · 五大训练模块详细交互设计

> 每个题型只写「页面 / 操作 / 判题+维度+反馈 / 强化」，反馈与强化复用 Part 1 的统一机制，只补题型专属点。

## 模块一 · 词汇训练

### 1. 词义匹配
- **页面**：顶部进度；中间一行英文单词 + 4 个中文释义选项；底部提交。
- **操作**：看单词 → 点一个释义 → 提交。
- **判题/维度**：选项 ID 比对 → **词汇**。反馈：「这个词在真题里常考『X』义，你选的是另一个义项」+ 高亮正确释义。
- **强化**：错后提示「看词根/前缀」→ 再试 → 类似词义题（同词根换词）。

### 2. 听音辨词
- **页面**：顶部进度；中间一个「播放」按钮 + 4 个单词选项；底部提交。
- **操作**：点播放（可重播）→ 听音 → 选单词 → 提交。
- **判题/维度**：选项比对 → **词汇 + 听力**。反馈：「你选的是形近词，注意 /iː/ 与 /ɪ/ 的区分」。
- **强化**：错后重播原音 + 慢速 → 再试 → 近似音辨词题。

### 3. 拼写强化
- **页面**：顶部进度；中间中文释义 + 首字母提示 + 文本输入框；底部提交。
- **操作**：看中文 → 键入英文单词 → 提交。
- **判题/维度**：文本归一化比对 → **词汇 + 写作**。反馈：定位拼错字母（高亮）+「双写/易错字母规则」。
- **强化**：错后提示错位字母 → 再试 → 同规则词拼写题。

---

## 模块二 · 句子训练

### 4. 句子排序（✅ 已建：reorder）
- **页面**：顶部进度；中间中文提示 + 打乱的英文碎片块；底部提交。
- **操作**：拖拽/点选碎片 → 排成句 → 提交。
- **判题/维度**：序列比对 → **长难句**。反馈：「主句是『…』，修饰语应紧跟被修饰词」+ 高亮错位碎片。
- **强化**：错后提示「先找主句」→ 再试 → 同类结构排序题。

### 5. 翻译训练
- **页面**：顶部进度；中间英文原句 + 4 个中文译文选项；底部提交。
- **操作**：读原句 → 选最佳译文 → 提交。
- **判题/维度**：选项比对 → **长难句 + 阅读**。反馈：「干扰项把『从句』翻成了『并列』」+ 高亮关键差异。
- **强化**：错后提示「看从句修饰谁」→ 再试 → 同句式翻译题。

### 6. 句型替换
- **页面**：顶部进度；中间原句 + 改写要求 + 4 个改写结果选项；底部提交。
- **操作**：读要求（如「改为被动」）→ 选正确改写 → 提交。
- **判题/维度**：选项比对 → **长难句 + 写作**。反馈：「改写改变了时态/主语，不符合要求」。
- **强化**：错后提示「先保持时态和主语」→ 再试 → 同规则替换题。

---

## 模块三 · 听力训练

### 7. 关键词识别
- **页面**：顶部进度；中间音频播放 + 题干「听出关键词」+ 4 个词选项；底部提交。
- **操作**：播放 → 听 → 选听到的关键词 → 提交。
- **判题/维度**：选项比对 → **听力**。反馈：「你选的是干扰词，原文关键词是重读的『…』」。
- **强化**：错后重播定位句 → 再试 → 同场景关键词题。

### 8. 听写训练
- **页面**：顶部进度；中间音频 + 空行（挖空句）；底部提交。
- **操作**：播放 → 听写缺失单词/短语 → 提交。
- **判题/维度**：文本比对 → **听力 + 写作**。反馈：定位拼写/漏词 +「连读导致听漏」提示。
- **强化**：错后提示「注意连读/弱读处」→ 再试 → 同句二次听写。

### 9. 信息匹配
- **页面**：顶部进度；中间音频 + 左侧 3 条信息（谁/时间/地点）；底部 3 个匹配选项。
- **操作**：播放 → 把信息与选项配对 → 提交。
- **判题/维度**：配对逐项比对 → **听力 + 阅读**。反馈：「你混淆了数字信息，注意 /fifteen/ 与 /fifty/」。
- **强化**：错后重播对应片段 → 再试 → 同类型数字/事实匹配题。

---

## 模块四 · 阅读训练

### 10. 信息定位（✅ 可复用 choice）
- **页面**：顶部进度；中间短文 + 问题「第 2 段提到…」+ 4 选项；底部提交。
- **操作**：读题 → 回原文定位 → 选答案 → 提交。
- **判题/维度**：选项比对 → **阅读**。反馈：「题干关键词对应第 X 段，你定位到了干扰段」。
- **强化**：错后提示「先找题干关键词」→ 再试 → 同段落定位题。

### 11. 长难句拆解（✅ 已建：reading_breakdown）
- **页面**：顶部进度；中间长句；底部「逐步拆解」按钮逐层展示主句→修饰→译文。
- **操作**：先自读 → 点「拆解」逐步看 → 点「我理解了」→ 下一句。
- **判题/维度**：无对错（学习型，不计分）→ **长难句 + 阅读**。反馈：拆解步骤本身即解析。
- **强化**：无错误路径；完成后进入配套的句子排序/翻译题巩固同一句。

### 12. 主旨判断
- **页面**：顶部进度；中间全文/段落 + 4 个主旨选项；底部提交。
- **操作**：读全文 → 选主旨 → 提交。
- **判题/维度**：选项比对 → **阅读**。反馈：「你选的是细节，不是主旨；主旨句在首/末句」。
- **强化**：错后提示「看首尾句」→ 再试 → 同文体主旨题。

---

## 模块五 · 写作训练

### 13. 句子改错
- **页面**：顶部进度；中间一句带下划线分段的句子（每段可点）；底部提交。
- **操作**：点选出错的那一段 → 提交。
- **判题/维度**：选中位置比对 → **写作 + 长难句**。反馈：「错误在『主谓一致/时态/冠词』处」+ 高亮。
- **强化**：错后提示「检查动词与主语」→ 再试 → 同语法点改错题。

### 14. 句型升级
- **页面**：顶部进度；中间简单句 + 升级要求 + 4 个升级版选项；底部提交。
- **操作**：读要求（如「合并为定语从句」）→ 选最佳升级 → 提交。
- **判题/维度**：选项比对 → **写作**。反馈：「你的选项改变了原意，升级要保留原义」。
- **强化**：错后提示「先保留主干信息」→ 再试 → 同结构升级题。

### 15. 模板训练
- **页面**：顶部进度；中间一个带挖空的写作模板句 + 4 个填空选项（或输入框）；底部提交。
- **操作**：看语境 → 填入正确短语/连接词 → 提交。
- **判题/维度**：文本/选项比对 → **写作**。反馈：「这里需要表『转折』的连接词，不是『因果』」。
- **强化**：错后提示「判断前后句逻辑关系」→ 再试 → 同逻辑连接词模板题。

# Part 3 · MVP 第一阶段优先开发顺序

核心判据（决定先后）：**能否复用现有卡片类型（choice / reorder / reading_breakdown）且证据写入路径落在 sentence / reading**。当前 `apply_learning_evidence` 只写 **长难句 + 阅读** 两个维度，词汇/听力/写作暂无写入路径。

| 批次 | 题型 | 理由 |
|---|---|---|
| **第一批（已具备/零成本）** | 句子排序、长难句拆解、信息定位、主旨判断、翻译训练 | 前两个已建成；后三个复用 choice，证据落在 sentence/reading |
| **第二批（低改动）** | 句型替换、句子改错、句型升级 | 复用 choice，走 sentence/reading 证据，只加题面数据 |
| **第三批（暂缓，需扩展）** | 词义匹配、听音辨词、拼写强化、听力 3 个、写作模板/升级的 writing 证据 | 需要：① 新能力维度写入路径（vocabulary/listening/writing，属 RPC/R9 扩展）② 音频资产 ③ 文本输入组件 |

**一句话结论**：MVP 先把「句子 + 阅读」两条能力链做到闭环（第一批+第二批共 8 个题型），词汇/听力/写作三个模块的题型先设计好、待 R9 扩展证据写入后再上线——这样不碰冻结层，又能立刻铺开可交付的训练闭环。
